# 主成分分析（PCA）重點整理

> **PCA（Principal Component Analysis）是一種非監督式的線性降維方法。**  
> 它會把多個可能高度相關的原始特徵，轉換成較少且彼此正交的主成分，並盡量保留資料中的主要變異資訊。

---

## 1. PCA 圖解原理

### 為什麼需要 PCA？

假設銀行客戶資料有很多特徵：

```text
年齡、收入、存款、貸款金額、交易次數、
APP 登入次數、網銀使用次數、信用評分……
```

這些特徵可能彼此高度相關，例如：

```text
收入 ↑
  ↓
存款 ↑
  ↓
投資金額 ↑
```

原本可能有 10 個特徵，但實際上只包含少數幾種主要資訊。

```text
10 個原始特徵
        ↓ PCA
3 個主成分

PC1：整體財務能力方向
PC2：數位活躍程度方向
PC3：信用風險方向
```

注意：主成分不是直接挑出某個原始欄位，而是原始特徵的線性組合。

---

### PCA 的核心思想

假設資料只有兩個特徵：

```text
X = 年收入
Y = 存款
```

資料分布如下：

```text
存款 Y
 ↑
 │                    ●
 │                 ●
 │              ●
 │           ●
 │        ●
 │     ●
 │  ●
 └────────────────────────→ 年收入 X
```

PCA 會重新尋找新的座標方向：

```text
存款 Y
 ↑
 │                    ●
 │                 ●
 │              ●
 │           ●
 │        ●
 │     ●
 │  ●
 └────────────────────────→ 年收入 X
        ╱
       ╱  PC1
      ╱
```

- **PC1**：資料變異量最大的方向
- **PC2**：資料變異量第二大的方向，且與 PC1 正交

PCA 的基本假設：

```text
變異量越大
    ↓
包含的資訊通常越多
    ↓
優先保留
```

## 2. PCA 完整流程

```text
原始資料
   ↓
標準化
   ↓
計算共變異數矩陣
   ↓
計算特徵值與特徵向量
   ↓
依特徵值大小排序
   ↓
選擇前 K 個主成分
   ↓
將資料投影到低維空間
```

---

### Step 1：標準化

不同特徵的數值範圍可能差很多：

```text
年齡：20～60
收入：500,000～2,000,000
```

若不先標準化，收入的數值尺度可能主導 PCA。

標準化公式：

```text
z = (x - 平均值) / 標準差
```

標準化後：

```text
平均值 = 0
標準差 = 1
```

實務上通常先使用：

```python
StandardScaler()
```

---

### Step 2：共變異數矩陣

共變異數用來判斷兩個特徵是否一起變化。

```text
收入 ↑、存款 ↑
→ 正共變異數

負債 ↑、信用評分 ↓
→ 負共變異數

兩者無明顯關係
→ 共變異數接近 0
```

範例：

```text
          收入    存款
收入      1.0     0.9
存款      0.9     1.0
```

代表收入與存款高度相關。

---

### Step 3：特徵值與特徵向量

```text
特徵向量 Eigenvector
= 主成分的方向

特徵值 Eigenvalue
= 該方向包含多少變異量
```

例如：

```text
PC1 特徵值 = 8.5
PC2 特徵值 = 1.5
```

總變異量：

```text
8.5 + 1.5 = 10
```

解釋變異比例：

```text
PC1 = 8.5 / 10 = 85%
PC2 = 1.5 / 10 = 15%
```

圖解：

```text
PC1 █████████████████ 85%
PC2 ███               15%
```

若只保留 PC1，仍可保留約 85% 的資料變異資訊。

---

### Step 4：形成主成分

假設原始特徵為：

```text
X1 = 收入
X2 = 存款
```

PCA 可能得到：

```text
PC1 = 0.7 × 收入 + 0.7 × 存款
PC2 = -0.7 × 收入 + 0.7 × 存款
```

因此：

```text
原始座標：收入、存款
        ↓
新座標：PC1、PC2
```

---

### Step 5：投影降維

原本資料在二維空間：

```text
        ●
      ●
    ●
  ●
```

投影到 PC1：

```text
        ●
        │
      ● │
      │ │
    ● │ │
    │ │ │
────●─●─●──────── PC1
```

結果：

```text
2 維資料
   ↓
1 維資料
```

這就是降維。

## 3. PCA 屬於哪一種機器學習？

```text
Machine Learning
│
├── 監督式學習
│
├── 非監督式學習
│      └── 降維
│             └── PCA
│
└── 強化學習
```

PCA 屬於：

```text
非監督式學習
    ↓
降維
    ↓
特徵抽取
    ↓
線性轉換
```

---

## 4. PCA 與特徵選擇的差異

### 特徵選擇

```text
原始特徵：A B C D E
選擇結果：A C E
```

保留的仍是原始欄位。

### PCA

```text
原始特徵：A B C D E
轉換結果：PC1 PC2
```

PCA 會建立新的特徵。

```text
Feature Selection = 挑選原始特徵
PCA               = 建立新的主成分
```

## 5. 實務應用

### 銀行客戶資料降維

```text
100 個客戶特徵
      ↓ PCA
15 個主成分
      ↓
保留約 95% 變異資訊
```

常見流程：

```text
StandardScaler
      ↓
PCA
      ↓
K-means
      ↓
客戶分群
```

---

### 詐欺偵測與異常分析

```text
交易資料
   ↓
StandardScaler
   ↓
PCA
   ↓
Isolation Forest / DBSCAN / 分類模型
```

PCA 本身不是詐欺分類器，而是負責降維與特徵抽取。

---

### 圖像壓縮

```text
100 × 100 圖像
= 10,000 個像素特徵
        ↓ PCA
較少主成分
        ↓
保留主要圖像結構
```

---

### 高維資料視覺化

```text
50 維資料
   ↓ PCA
2 維資料
   ↓
繪製散點圖
```

可用來觀察：

```text
群集
離群值
資料分布
```

---

### 機器學習前處理

```text
原始資料
   ↓
StandardScaler
   ↓
PCA
   ↓
SVM / Logistic Regression / K-means
```

可能改善：

- 訓練速度
- 記憶體使用量
- 特徵冗餘
- 部分雜訊問題

但 PCA 不保證一定提高模型準確率。

## 6. PCA 優缺點

### 優點

| 優點 | 說明 |
|---|---|
| 降低維度 | 減少特徵數量 |
| 減少冗餘 | 處理高度相關特徵 |
| 提升效率 | 降低訓練時間與記憶體需求 |
| 方便視覺化 | 將高維資料轉成 2D 或 3D |
| 降低部分雜訊 | 捨棄低變異主成分 |
| 改善維度災難 | 降低高維空間造成的問題 |

### 缺點

| 缺點 | 說明 |
|---|---|
| 可解釋性降低 | 主成分是多個特徵的組合 |
| 只能處理線性結構 | 對非線性資料效果有限 |
| 對尺度敏感 | 通常需要先標準化 |
| 對離群值敏感 | 離群值會影響變異方向 |
| 可能遺失資訊 | 降維必然可能造成資訊損失 |
| 不使用標籤 | 高變異方向不一定最適合分類 |

---

## 7. PCA 與其他演算法比較

### PCA vs K-means

| 比較項目 | PCA | K-means |
|---|---|---|
| 類型 | 非監督式 | 非監督式 |
| 目的 | 降維 | 分群 |
| 輸出 | 主成分 | 群集標籤 |
| 核心概念 | 最大變異量 | 距離與群中心 |

```text
PCA：100 個特徵 → 10 個主成分
K-means：10,000 位客戶 → 5 個群體
```

---

### PCA vs LDA

| 比較項目 | PCA | LDA |
|---|---|---|
| 類型 | 非監督式 | 監督式 |
| 是否需要標籤 | 否 | 是 |
| 目標 | 最大化資料變異 | 最大化類別區隔 |
| 主要用途 | 降維、視覺化 | 分類、監督式降維 |

## 8. Python 簡單範例

使用 Iris Dataset，將 4 維特徵降為 2 維。

```python
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# 1. 載入資料
iris = load_iris()
X = iris.data

print("原始資料維度：", X.shape)

# 2. 標準化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 3. 建立 PCA，保留 2 個主成分
pca = PCA(n_components=2)

# 4. 執行降維
X_pca = pca.fit_transform(X_scaled)

print("PCA 後資料維度：", X_pca.shape)

# 5. 查看各主成分解釋的變異比例
print("各主成分解釋變異比例：")
print(pca.explained_variance_ratio_)

# 6. 查看總解釋變異比例
print("總解釋變異比例：")
print(pca.explained_variance_ratio_.sum())
```

可能輸出：

```text
原始資料維度：(150, 4)
PCA 後資料維度：(150, 2)

各主成分解釋變異比例：
[0.7296 0.2285]

總解釋變異比例：
0.9581
```

代表：

```text
PC1 約保留 72.96%
PC2 約保留 22.85%

合計約保留 95.81% 的變異資訊
```

## 9. 自動保留 95% 變異資訊

```python
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

iris = load_iris()
X = iris.data

X_scaled = StandardScaler().fit_transform(X)

# 自動決定需要多少主成分，才能保留至少 95% 變異資訊
pca = PCA(n_components=0.95)

X_pca = pca.fit_transform(X_scaled)

print("原始維度：", X.shape)
print("PCA 後維度：", X_pca.shape)
print("總解釋變異比例：", pca.explained_variance_ratio_.sum())
```

## 11. 常見考試陷阱

### 陷阱一

> PCA 會選出最重要的原始特徵。

```text
錯誤
```

PCA 是特徵抽取，不是特徵選擇。

---

### 陷阱二

> PC1 是對分類結果最重要的方向。

```text
錯誤
```

PC1 是資料變異量最大的方向，不一定是最適合分類的方向。

---

### 陷阱三

> PCA 不需要標準化。

```text
不一定正確
```

若各特徵尺度差異很大，通常必須先標準化。

---

## 一句話總結

> **PCA 是透過尋找資料最大變異方向，將高維資料轉換成較少主成分的非監督式線性降維方法。**
